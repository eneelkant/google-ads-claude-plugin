# Google Ads Setup

Use this command to configure Google Ads API credentials for the Google Ads Manager plugin.

The setup should guide the user through:

1. Google Ads Developer Token
2. Google Cloud service account credentials
3. Google Ads Customer ID
4. Login Customer ID, if using an MCC account
5. Securely storing the required credentials in the user's local environment

Never request users to paste credentials into a public GitHub repository.

After configuration, verify that the Google Ads API connection works before attempting campaign management operations.
